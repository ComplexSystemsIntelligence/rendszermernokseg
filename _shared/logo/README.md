# A Pannon Egyetem logói

Forrás: a Pannon Egyetem hivatalos 2026-os alaplogó-készlete (PE Média szerkesztőség, Arculat, „PE ALAP címer logó 2026”, SVG).

| Fájl | Tartalom | Használat a könyvekben |
|:--|:--|:--|
| `PE_cimer_nevjel_fekvo_kek.svg` | fekvő címer + névjel, kék | webes oldalsáv, PDF-impresszum, nyitóoldal, README |
| `PE_cimer_nevjel_fekvo_feher.svg` | fekvő címer + névjel, fehér | PDF-címoldal és részcímoldalak kék sávja, webes lábléc |
| `PE_cimer_nevjel_allo_kek.svg` / `_feher.svg` | álló címer + névjel | PDF hátsó borító |
| `PE_cimer_kek.svg` / `_feher.svg` | címer névjel nélkül | tartalék |
| `PE_betulogo_kek.svg` | P+e betűlogó, kék | favicon, Excel-sablonok |
| `PE_betulogo_feher.svg` | a betűlogó negatív (fehér) változata | vízjel a kék sávokon |

A `PE_betulogo_feher.svg` és a `PE_betulogo_negyzet.svg` (négyzetes vászon a faviconhoz) a hivatalos kék betűlogóból készült, a rajzolat változtatása nélkül. A `pdf/` mappa a LaTeX-hez, a `png/` mappa a faviconhoz és a notebookokhoz tartalmazza ugyanezeket a rajzolatokat (`rsvg-convert`).

A logók a Pannon Egyetem arculati elemei. A könyvek CC BY-NC-SA 4.0 licence ezekre nem terjed ki; a könyv átdolgozott, nem a Pannon Egyetem által kiadott változatain a logók nem használhatók.
