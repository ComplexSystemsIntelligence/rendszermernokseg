# Excel-sablonok

A Gyakorlati útmutató eszközlapjainak letölthető munkafüzetei. Excelben, LibreOffice Calcban és Google Táblázatokban is használhatók. Mindegyik egy *Útmutató* lappal kezdődik (jelmagyarázat, forrás), és a kézikönyv futó eseteinek egyikével kitöltött példát tartalmaz.

**Jelmagyarázat:** sárga háttér, kék betű: kitöltendő cella; halványkék háttér: képlet, ne írd felül.

A sablonokat a `_gen_*.py` szkriptek állítják elő (`python3 gyakorlat/sablonok/_keszit_mind.py --recalc`); kézzel ne szerkeszd őket, mert a következő előállítás felülírja a változást.
